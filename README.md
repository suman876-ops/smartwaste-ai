# SMARTWASTE AI

SMARTWASTE AI is a concept for AI-assisted waste classification and smarter waste-handling workflows.

**Status:** Concept · Hackathon project — this repository holds the concept landing page only.
There is no working prototype yet.

- **Live page:** https://suman876-ops.github.io/smartwaste-ai/
- **Portfolio:** https://suman876-ops.github.io/suman-portfolio/

## What's here

```
index.html      the whole page — HTML, CSS and a little JavaScript
assets/og.png   1200x630 share / hero image
favicon.svg     site icon
```

## Running locally

No build step. Open `index.html`, or serve the folder:

```
python3 -m http.server 8000
```
