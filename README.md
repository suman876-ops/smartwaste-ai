# SMARTWASTE AI

A concept for AI-assisted waste classification and smarter waste-handling workflows.

**Status:** Concept — hackathon project. This repository holds the landing page only. There is no working prototype yet.

**Live:** https://suman876-ops.github.io/smartwaste-ai/

## Overview

Mixed waste is the main reason recycling streams fail. The concept is a classification layer that identifies waste type from an image and routes it to the right handling path, with dashboards for collection teams.
